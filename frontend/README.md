# ChakriTrack Web

Next.js 16 (App Router) + TypeScript + Tailwind 4. Web app, admin and SEO/tool pages for ChakriTrack.
Agent/dev instructions: [`AGENTS.md`](./AGENTS.md). Product spec: [`../PROJECT_SPEC.md`](../PROJECT_SPEC.md).

```bash
cp .env.example .env.local
npm install
npm run dev      # http://localhost:3000
npm run build && npm run lint
```
